# Skill icon sources

Apple, PyTorch, TensorFlow, OpenCV, NumPy, pandas, Matplotlib, GitHub, Python, YAML, JSON, Plotly, Streamlit, SQLite, HTML5, CSS3, JavaScript, Node.js, FastAPI, Swift, Anaconda, VS Code, Jupyter, Xcode, Playwright, and GitHub Actions SVGs: https://github.com/devicons/devicon (MIT; see LICENSE-devicon).
ONNX, SciPy, Ultralytics, arXiv, Pydantic, Claude, and uv SVGs: https://github.com/simple-icons/simple-icons (CC0; see LICENSE-simple-icons.md).
Technology names and logos belong to their respective owners. The Apple mark identifies the Core ML platform; the PyTorch mark identifies Torch Lite. The Python mark identifies the pathlib and dataclasses standard-library modules.

Research projects without a dedicated bundled logo use the GitHub icon for repository links. U-Net uses the arXiv icon for its paper link. No custom project symbols are displayed.

Unused legacy assets remain in this folder: the Meta and Hugging Face marks from Simple Icons, and original line symbols from earlier drafts.

## Motion capture company icons

OptiTrack and Motive use the official site icon from https://docs.optitrack.com/. Bertec uses the official site icon from https://www.bertec.com/. These company-owned assets identify the linked products and companies; they are not covered by the icon-library licenses above.

The OpenAI mark used for Codex is from Simple Icons v15.0.0: https://github.com/simple-icons/simple-icons/blob/15.0.0/icons/openai.svg (CC0).
